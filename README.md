# Виселица Online (соревнование двух игроков)

Это браузерная онлайн-версия на ASP.NET Core 8 + SignalR. Игроки могут подключаться с разных устройств через браузер. Оба угадывают одно общее слово; у каждого собственные ошибки и прогресс. Кто первым угадывает слово, получает очко, после чего сервер открывает следующее слово для обоих. Игра длится 5 минут после подключения второго игрока.

## Что нужно
- Установленный .NET 8 SDK
- Для игры с разных устройств через интернет — разместить приложение на сервере/хостинге с поддержкой ASP.NET Core и HTTPS.
- Для проверки в одной Wi-Fi сети можно запустить приложение на компьютере и открыть его по локальному IP компьютера, если разрешён входящий порт в брандмауэре.

## Запуск на своём компьютере
1. Распакуй архив.
2. Открой терминал в папке, где лежит `HangmanOnline.csproj`.
3. Выполни:
   ```bash
   dotnet run --urls http://0.0.0.0:5080
   ```
4. На этом компьютере открой `http://localhost:5080`.
5. Чтобы подключить другое устройство в той же Wi-Fi сети, узнай локальный IPv4 компьютера (`ipconfig` в Windows) и открой на втором устройстве `http://АДРЕС-КОМПЬЮТЕРА:5080`.

## Игра через интернет
`localhost` доступен только на том устройстве, где запущен сервер. Чтобы играть из разных мест, приложение нужно опубликовать на публичном хостинге с поддержкой ASP.NET Core. После публикации оба игрока заходят на один и тот же HTTPS-адрес.

## Важно
- Сервер хранит комнаты в памяти. После перезапуска сервера комнаты исчезнут.
- Код комнаты состоит из 6 символов.
- Игра рассчитана на двух игроков.
- Если один игрок отключается, текущая партия завершается.


## Публикация в интернете через Render
1. Создай репозиторий на GitHub и загрузи туда содержимое этой папки (включая `Dockerfile` и `ozhegov.txt`).
2. Зарегистрируйся на Render и выбери **New + → Web Service**.
3. Подключи свой GitHub и выбери созданный репозиторий.
4. В настройках выбери **Docker** как Runtime/Language. Render использует `Dockerfile` в корне репозитория.
5. Для начала можно выбрать Free plan, если он доступен для твоего аккаунта/региона, затем нажми **Deploy Web Service**.
6. Дождись статуса Live и открой адрес вида `https://имя-сервиса.onrender.com`.
7. Отправь этот HTTPS-адрес другу. Оба открываете одну и ту же ссылку, один создаёт комнату, второй вводит код.

Примечания:
- Бесплатный веб-сервис Render может засыпать после периода бездействия, поэтому первое открытие иногда занимает некоторое время.
- Комнаты хранятся в оперативной памяти; при перезапуске или новом деплое текущая игра может потеряться.
- Перед публикацией проверь игру локально. В этой среде .NET SDK недоступен, поэтому компиляция проекта здесь не проверялась.
